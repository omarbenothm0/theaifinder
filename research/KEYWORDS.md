# Keyword & Search Opportunity Inventory

**Last updated:** 2026-08-11  
**Entries:** 0

Master inventory of keywords, queries, and search-intent opportunities. **No invented search volume, CPC, or traffic numbers.**

---

## Rules

- Every keyword entry must cite **observed evidence** or mark demand metrics as **NOT VERIFIED**
- Map each keyword to an **AI Finder destination** (see Research Bible §9)
- Check duplicates — semantic equivalents are not new keywords
- Compare against existing routes: tool pages, `/category/*`, `/for/*`, `/compare/*`, catalog, finder

---

## Entry template

```markdown
### [Keyword or query phrase]

| Field | Value |
|---|---|
| **Keyword** | Exact phrase researched |
| **Source** | Where this keyword came from (tool, owner, SERP observation, keyword tool export, etc.) |
| **Evidence type** | VERIFIED FACT / OBSERVATION / … |
| **Observed evidence** | What was actually seen — NOT invented volume |
| **Intent** | Informational / commercial / navigational / comparison / other |
| **Relevant tool(s)** | Tool name(s) or NOT VERIFIED |
| **Existing AI Finder destination** | URL or none |
| **Proposed destination** | If none exists — category, tool, persona, comparison, NEW, or NO USEFUL DESTINATION |
| **Status** | DISCOVERED / RESEARCHED / VERIFIED / PROPOSED / APPROVED / IMPLEMENTED / REJECTED |
| **Priority** | Owner-set or NOT VERIFIED |
| **Date researched** | YYYY-MM-DD |

**Notes:**
- …
```
